# Authentication Service:
#### 1. Вход пользователя в систему:

### POST /login

##### Тело запроса:
```json
{
  "username": "user@example.com",
  "password": "password"
}
```

##### Ответ: 200 OK
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR..."
}
```

#### 2. Регистрация пользователя в системе:

### POST /register

##### Тело запроса:
```json
{
  "firstname":"Ivan",
  "lastname":"Ivanov",
  "username":"user@example.com",
  "email":"user@example.com",
  "password":"password",
  "role": "User"
}
```

##### Ответ: 201 Created
```json
{
    "message": "User registered and payment account created successfully."
}
```

# Booking  Service:
#### 1. Создание нового бронирования медицинской услуги
### POST /booking

##### Тело запроса:
```json
{
  "MedServiceId": "medServiceId",
  "MedServiceName": "medServiceName",
  "MedicalWorkerId": "medWorkerId",
  "MedicalWorkerFullName": "medWorkerName",
  "TimeSlotId": 9,
  "TimeSlot":"2025-02-27T05:00-2025-02-27T05:30",
  "Amount": "price"
}

```

##### Ответ: 201 Created
```json
{
  "message": "Заказ успешно создан."
}
```

# Scheduling Service:
#### 1. Получение доступного расписания врача, выполняющего медицинскую услугу

### GET /{{baseUrl}}/schedule/GetAllSlots?medicalWorkerId={{medWorkerId}}&date={{startDate}}

##### Ответ: 200 OK
```json
[
  {
    "id": 7,
    "medicalWorkerId": 1,
    "startTime": "2025-02-27T11:00:00",
    "endTime": "2025-02-27T11:30:00",
    "isAvailable": true
  },
  {
    "id": 8,
    "medicalWorkerId": 1,
    "startTime": "2025-02-27T11:30:00",
    "endTime": "2025-02-27T12:00:00",
    "isAvailable": true
  },
]
```
#### 2. Добавление расписание врача (генерация нескольких окошек)
### POST /schedule/create

##### Тело запроса:
```json
{
  "medicalWorkerId": "medWorkerId",
  "medServiceId": "medServiceId",
  "startDate": "2025-02-27T08:00:00",
  "endDate": "2025-02-27T12:00:00",
  "timeSlotInMinutes": 30
}
```

##### Ответ: 201 Created
```json
{
  "message": "Окошки для записи созданы"
}
```

# Payment  Service:
#### 1. Пополнение баланса
### POST /payment/deposit
##### Тело запроса:
```json
{
  "amount": 55,
}
```
##### Ответ: 200 OK
```json
{
    "message": "Deposit successful.",
    "balance": 55
}
```

#### 2.	Получение информации о балансе
### GET /payment/account
##### Ответ: 200 OK
```json
{
    "id": 2,
    "userId": 2,
    "balance": 110,
    "isActive": true
}
```
